# Notepad++ Markdown Usage Guide

## Creating Markdown Files
1. File → New
2. Save As → <filename>.md
3. Notepad++ applies Markdown rules automatically.

## Enabling Syntax Highlighting
Language → M → Markdown

## Installing Markdown Preview
1. Plugins → Plugins Admin
2. Install:
   - MarkdownViewer++ or
   - MarkdownPanel
3. Restart Notepad++
4. Open preview panel via Plugins menu.

## Productivity Shortcuts
- Ctrl + D — duplicate line
- Ctrl + S — save
- Ctrl + Shift + Up/Down — move line
- Alt + Shift + Arrow — block selection
- Ctrl + F — find
- Ctrl + H — replace
- Ctrl + Shift + F — find in all files
- Ctrl + Shift + S — save all

## Recommended Setup
- Dock preview panel on right side
- Open Folder as Workspace to manage Git repos
